# Replication materials

Analysis code (Python, R) and aggregate result files for "Chance, Persistent Advantage, and the
Generative-AI Era in Open-Source Package Careers" (Hazem Ibrahim and Yasir Zaki, ICWSM 2027).
Pre-registration: https://osf.io/ruc7h/.

Every figure and table is regenerable from the JSONs under `experiments/stage3_analysis/results_v2/`,
`results_v2/posthoc2/` and `results_v2/posthoc3/` (the post-acceptance robustness checks,
`experiments/stage3_analysis/run_posthoc3.py`). All input data come from public sources (GH Archive,
Libraries.io, Ecosyste.ms); no individual-level data are distributed. Python dependencies:
`experiments/requirements.txt`.
