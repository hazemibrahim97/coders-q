# Replication materials

Analysis code (Python, R) and aggregate result files for the paper. Every figure and table
is regenerable from the JSONs under `experiments/stage3_analysis/results_v2/` and
`results_v2/posthoc2/`. All input data come from public sources (GH Archive, Libraries.io,
Ecosyste.ms); no individual-level data are distributed. Python dependencies:
`experiments/requirements.txt`.
